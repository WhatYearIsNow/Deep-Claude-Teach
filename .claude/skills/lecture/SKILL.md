# lecture —— 课前一条龙

## 🔴 前置（自动执行，不提问）

1. 读 `CLAUDE.md` → 确定科目（路径含 `物理-郭同学`→物理 / `数学-崔同学`→数学 / `数学-沈同学`→数学）
2. 读对应 workflow §七（偏好+家长要求）+ §八（检查清单）+ §九（教学沉淀）
3. 读对应学生 `index.md` + `log.md` 最后 5 条
4. 读对应学生 `wiki/学生/` 画像 + `wiki/进度/课程进度`
5. **🔴 检索资料库（强制，禁止跳过）**：
   - `ls` 列出学生专属 `参考题库/` → `ls` 列出共享教辅目录结构
   - **所有参考教辅 PDF 均为扫描图片版**，提取方法：PyMuPDF 渲染页面为 PNG → `node vision.js` 读取内容（详见 shared workflow §1.4.1）
   - **严禁** pdftotext 返回空就放弃——那只是说明是扫描版，换 vision.js 即可
   - 选题严格按顺序：⓪用户指名 → ①专属题库 → ②共享教辅 → ③系统课程 → ④自编
   - **禁止不看资料库就凭记忆编题**
6. 如有 `作业/` 目录 → 逐图读取（用 `node vision.js`，不用 Read）、对比上次讲义，标记对错
7. 如对应学生 `讲义/` 下有本次课日期文件夹（或最新的日期文件夹），扫描其中非讲义的图片（家长微信截图）→ `node vision.js` 识读，提取家长关切，作为选题和风格调整依据

## 🟢 交互确认（只问库里没有的）

> **前置已自动读取**：学生画像、家长要求、课程进度、上次简报、作业批改——这些全在 vault 里，不需要问。
> **Skill 只问两件事**：① 用户没明说时，确认学生和主题；② 有没有今天才出现的临时要求。

### 选题来源判定

```
用户消息中指名了资料？
  ├─ 是（如"用必刷100讲出函数讲义""用百年真题选题"）
  │   → 🔴 该资料为第一优先级，跳过默认检索顺序
  │   → 直接从指名的资料中选题
  └─ 否 → 按默认顺序：专属题库 → 共享教辅 → 系统课程 → 自编
```

### 流程

1. 用户消息里有的 → 直接用
2. 用户没说但库里有的 → 前置已读，直接用
3. 用户没说、库里也没有的 → 问（通常只需问：学生？主题？临时要求？）
4. 汇总确认 → 生成

### 格式

用 `AskUserQuestion`，点击选择。

## 🟢 执行 · 生成讲义

### 讲义结构

```
Part 1 · 课前回顾（5-8 min）
  → 作业错题讲评 + 方法纠偏
  → 只有存在作业/上次课遗留问题时才有此部分

Part 2 · 新内容（主体）
  → 选题优先级：学生专属参考题库/ → 数学/参考教辅/ → 自编
  → 来源标注：教师版必标，学生版只标专属题库
```

### 学生版铁律

- 零 `> ` 引用块、零 AI 味 meta
- 题目 + 充足留白（`<br>` 8-10 个）
- 课前回顾部分的题目重现在学生版

### 教师版铁律

- 对照学生版生成，口语化黑板体
- 箭头链推导、先思路后过程、揪易错点
- 所有计算不跳步
- 每道题课堂引导语 + ⚠️ 陷阱预警
- 关键结论 `\boxed{}`
- 答案必核对：对照 PDF 参考答案
