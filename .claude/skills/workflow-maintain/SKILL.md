# maintain —— Vault 维护

## 🔴 前置

1. 读 `CLAUDE.md` + 两份 workflow

## 🟢 分步确认

**① 范围？** [健康检查 / 工作流升级 / 两者都要]

**② 科目？** [数学 / 物理 / 两科]

**③ 确认** → 开始。

## 🟢 执行

### 健康检查
- 死链：逐页检查 wiki 和 index 中的 wikilink 是否有效
- 过时信息：学生画像、进度、log 有无过时
- 矛盾：两科 workflow 有无互相矛盾的规范
- 缺失：必需页面（index/log/wiki/错题）是否齐全

### 工作流升级
- 审查 workflow 结构是否合理
- 更新 §九（教学沉淀）中的过时条目
- 确保两科 workflow + shared workflow 一致性
- 版本号升级 + 变更记录
