# feedback —— 课后一条龙

## 🔴 前置（自动执行，不提问）

1. 读对应 workflow §一（快速上手）+ §七（偏好）+ §八（检查清单）
2. 读对应学生 `wiki/学生/` 画像 + `wiki/进度/课程进度`

## 🟢 交互确认（只问库里没有的）

> **前置已自动读取**：学生画像、课程进度——都在 vault 里。
> **Skill 只确认**：学生（如上下文不明确）、逐字稿位置（如找不到）。

1. 学生不明确 → 问
2. 逐字稿自动找 `讲义/MMDD/` 下的 .txt，找不到才问路径
3. 汇总确认 → 开始

## 🟢 执行

### 1. 读逐字稿 + 讲稿

- 逐字稿直接 `Read`（TXT 格式）
- 同目录找讲稿 PDF → `pdftotext -layout` 提取
- 关注：学生发言次数 + 卡点 + 反馈原话 + 老师教学失误

### 2. 生成课程简报

保存到 `讲义/MMDD/MMDD 课程简报.md`。必含：
- 课程概览（课题、时长、结构）
- 课堂实况（每题耗时 + 学生反应）
- 本次课最重要的教学成果
- 学生状态分析
- 工作流优化建议
- 下次课预告

### 3. 生成课程反馈

保存到 `讲义/MMDD/MMDD 课程反馈.md`。必含：
- 上课时间、内容、效果、下次预告
- **纯文本格式**，无任何 markdown（给家长微信发）
- 不展开分析——分析归简报，反馈只陈述事实
